初回のみ：管理者トークンの作り方
  1. 下のリンクからGitHubのトークン作成画面を開きます。
  2. Repository access は「Only select repositories」を選び、livenova-closing-flowchartだけを指定します。
  3. Repository permissions の「Contents」をRead and writeにします。
  4. 作成されたトークンをコピーし、この画面へ貼り付けます。
